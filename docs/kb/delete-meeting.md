## Short answer
Open the meeting in **History**, select the trash button and confirm. This cannot be undone.

## Steps
1. Select **History** and open the meeting.
2. Select the trash button at the top.
3. Confirm **Delete this meeting and all its cards? This cannot be undone.**
4. The meeting, transcript, cards, cached research and recording are removed. Backups and files you downloaded are not changed.
5. If the recording file cannot be deleted, the meeting is kept. Close anything using the file and try again.
6. If the app says the server did not respond, check that it is running and try again.
