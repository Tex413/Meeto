## Short answer
The web trial allows 20 minutes of Whisper-transcribed audio and 2 document uploads. About 7 days after the trial time is used up, the server **deletes the trial account's meetings, cards and documents** unless the account has been licensed.

## Steps
1. Check the toolbar badge, for example **12 min trial left** or **Trial expired**. **Generate transcript** also uses trial time.
2. Note that removing a document does not give an upload back.
3. When trial time is used up, you cannot start a new meeting record, transcribe with Whisper or upload documents.
4. Before the deletion date, copy what you need: read transcripts in **History**, and use **Export CSV** for saved cards (the CSV has no transcripts).
5. To keep using the app, activate a license: select the trial badge, paste your key and select **Activate**. Deleted data cannot be restored from the app.
