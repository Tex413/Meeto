## Short answer
Add tasks manually or extract them from a transcript, then export or send them to Microsoft To Do.

## Steps
1. Expand **To-dos** and type an item in **Add action item**; press Enter or select plus.
2. Select **Extract** to generate suggestions from the transcript and review them.
3. Select the toolbar's **Export action items** button, or open **To Do** and select **Export .ics for Outlook**.
4. To send to Microsoft To Do, use **Save & sign in** with your Microsoft app client ID, complete device login, choose a list, then select **Send tasks**.
