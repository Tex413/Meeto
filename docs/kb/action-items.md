## Short answer
Type items or use **Extract**, then export them before you leave the page.

## Steps
1. Type in **Add action item…** and press Enter or select plus.
2. Or select **Extract** after at least 20 words of transcript. It reads about the last 400 words; the button is then labelled **Extract from transcript**. Review the results.
3. Check an item when it is done, or select **Remove** to delete it.
4. Select **Export action items** on the toolbar to download `action-items.txt` with open and completed items.
5. For a task file in `.ics` format, select **To Do**, then **Export .ics for Outlook**. This button appears only while no Microsoft client ID is saved. It contains open items only; import support depends on your other program.
