## Short answer
Create a meeting with **Record**, start microphone transcription separately with **Start listening**, and finish with **End**.

## Steps
1. Inform participants of capture and obtain consent.
2. Enter a **Session title** and optional **Context**.
3. Select **Record** to create the meeting record.
4. Select **Start listening** to transcribe microphone audio. Select it again to stop listening.
5. Select **End** to save the meeting and stop any active capture.
