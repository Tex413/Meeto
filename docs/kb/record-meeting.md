## Short answer
**Record** creates the saved meeting and **Start listening** opens the microphone; use both. End with **Stop**, then **End**.

## Steps
1. Tell participants an AI is present and get their consent. The app has no consent step.
2. If an earlier meeting is still on screen, select **Clear all** before you start. It does not ask for confirmation.
3. Enter a **Session title** and optional **Context**.
4. Select **Record**.
5. Select **Start listening** and allow the microphone. Without **Record**, nothing is saved.
6. Select **Stop** to stop the microphone at any time; **Start listening** resumes.
7. To finish, select **Stop**, wait a few seconds for the last words, then select **End**. The badge shows **Saved**.
8. Do not select **Clear all** while a meeting is active, because the next automatic save replaces the saved transcript with the cleared one.
