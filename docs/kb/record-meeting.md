## Short answer
**Record** creates the saved meeting and **Start listening** asks for consent, then opens the microphone. If no meeting is active, **Start listening** creates one. End with **Stop**, then **End**.

## Steps
1. Have everyone present: nothing is captured until the [consent step](meeting-consent.md) is completed.
2. If you need the to-dos of a meeting you ended, export them first: starting the next meeting clears the live screen.
3. Enter a **Session title** and optional **Context**.
4. Select **Record**.
5. Select **Start listening**, complete **Consent before capture** and allow the microphone.
6. Select **Stop** to stop the microphone at any time; **Start listening** resumes. To end consent and stop all capture, select **Withdraw consent · stop all capture**.
7. To finish, select **Stop**, wait a few seconds for the last words, then select **End**. The badge shows **Saved**.
8. Do not select **Clear all** while a meeting is active, because the next automatic save replaces the saved transcript with the cleared one.
