## Short answer
Cards appear as the app detects topics in the live transcript; filter or auto-clear the live panel as needed.

## Steps
1. Add relevant **Context** or documents and start listening.
2. Review generated cards in **Insight cards**; verify factual claims independently when a source is not shown.
3. Type in **Filter cards** to narrow the list. Use the clear icon to reset it.
4. Select an **Auto-clear** interval if you want unpinned cards to fade from the live pane. Use **History** for saved meeting cards.
