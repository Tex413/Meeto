## Short answer
Nothing captures until consent is recorded for the current meeting. The app announces that it is an AI and what it will capture, and the host confirms that everyone present agreed. The wording is a draft that **no lawyer has approved**, and the record is the host's statement, not proof that anyone consented.

## Steps
1. Select **Start listening** or **Record A/V**. A meeting is created if none is active, and **Consent before capture** opens.
2. Let everyone hear the announcement. It says what is captured, what is kept and which cloud service receives anything. For **Record A/V**, first select **Start announcement clip and speak**: the microphone then records only the announcement and answers, which become part of the recording. The clip is discarded if you decline or close the dialog, or after 3 minutes.
3. If the voice cannot speak, or you selected **Mute voice**, read the whole announcement aloud and check **I read the whole announcement aloud to everyone present**.
4. Only if everyone agreed, check **Everyone present heard it and agreed**, type your name and select **Record consent and start capture**.
5. If anyone refuses, select **Decline · capture stays off**. Closing the dialog or pressing Escape also declines, and declining stops all capture.
6. While consent is recorded, a bar at the bottom shows what is being captured. If someone joins late, select **Someone joined**: capture stops and the announcement is made again.
7. If anyone changes their mind, select **Withdraw consent · stop all capture**.
8. Expect to be asked again for a new capture type, each new A/V recording, a new meeting, or a change of AI provider, AI key or Microsoft connection. There is no "do not ask again".
9. Saved with each meeting: time, wording version, announcement, capture types, destination, who confirmed, and when and why consent ended. The history screen does not show these records. Deleting the meeting deletes them.
10. If you add a capture type while **Record A/V** is running, the new announcement is only picked up through the recording's microphone and system audio. If someone declines then, recording stops, and the part already recorded, including that exchange, is saved.
11. Ask a lawyer what your meetings require. This step is not shown to meet any particular law.
