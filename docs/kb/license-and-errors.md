## Short answer
Use the message shown by the app to check licensing, the configured AI key, or microphone permission.

## Steps
1. For a trial-ended dialog, enter an issued key and select **Activate**, or contact your administrator.
2. For an AI connection error, open **Settings**, check the selected provider and saved-key status, then select **Test AI**.
3. For a microphone-denied error, grant microphone permission in your browser or operating system and select **Start listening** again.
4. If using Web Speech in Electron, switch to **Whisper**; the Web Speech control is marked Chrome only.
