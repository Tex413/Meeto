## Short answer
Open the app, sign in, save an OpenAI or Anthropic API key, get everyone's consent, then select **Record** and **Start listening**. If a Meeteor screen shows the label `Meetintel`, you are in the right app.

## Steps
1. Web app: open the address your administrator gave you (a local server on the default port is `http://localhost:7432`). Select **Create account**, or sign in. Desktop app: start it and activate your license if asked; it has no sign-in.
2. In **Settings**, choose the **AI Provider** and **Model**, paste the matching API key and select **Save**.
3. This build sends meeting text to the AI provider you choose. Before any capture, the app opens **Consent before capture**; see [the consent step](meeting-consent.md).
4. Enter a **Session title** and select **Record** to create the saved meeting.
5. Select **Start listening**, complete the consent step with everyone present, and allow microphone access. The transcript appears in **Live transcript**, and cards appear in **Insight cards** as topics are detected.
6. When finished, select **Stop**, wait a few seconds, then select **End**.
