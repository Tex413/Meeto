## Short answer
Allow the app to use the microphone in your browser or operating system, then start listening again.

## Steps
1. In your browser's site settings, allow the microphone for the app's address.
2. In your operating system's privacy settings, allow microphone access for the browser or desktop app.
3. If you reach a web app from another computer without HTTPS, ask your administrator; browsers generally allow microphones only on HTTPS or `localhost`.
4. Reload the page.
5. Select the correct microphone, then **Start listening**.
