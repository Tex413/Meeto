## Short answer
This version does not show saved to-dos in History or load them back after a page reload. They are also not in the CSV export. Export them while they are on screen.

## Steps
1. If the list is still on screen, select **Export action items** now.
2. Do this before reloading, signing out, closing the app, selecting **Clear all** or starting another meeting after **End**.
3. If the list is already gone, check files you exported earlier, or Microsoft To Do if you sent them.
4. If neither has them, read the meeting's **Transcript** in **History** and re-enter the items. The screens offer no way to restore the list.
