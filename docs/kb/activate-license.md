## Short answer
Copy your key from the payment success page, then paste it into the web trial dialog or the desktop activation screen. The app does not email the key, and there is no License section in Settings.

## Steps
1. To buy, select **See pricing** in the trial dialog, then **Get annual plan** or **Get lifetime license**. If checkout is not set up, a message appears and nothing is charged.
2. On **Payment confirmed!**, select **Copy key** and store it safely.
3. Web app: select the trial badge, paste the key under **Already have a license key?** and select **Activate**. The dialog's heading says the trial has ended even if time remains.
4. Desktop app: on **Activate Meetintel**, paste the key into **License key** and select **Activate**.
5. If the success page shows **Key unavailable**, contact your administrator or support with your payment receipt. Never include a license key in a support message.
