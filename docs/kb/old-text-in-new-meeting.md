## Short answer
**End** does not empty the live screen. Select **Clear all** after one meeting has ended and before you select **Record** for the next.

## Steps
1. Make sure the earlier meeting has ended with **End**.
2. If you need its to-dos, select **Export action items** first.
3. Select **Clear all** (trash icon on the toolbar). There is no confirmation. Saved meetings and documents are not deleted.
4. Check **Context**; it is not cleared and is kept in your browser. Edit or delete it yourself.
5. Select **Record** for the new meeting.
