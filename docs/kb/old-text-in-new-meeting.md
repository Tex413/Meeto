## Short answer
**End** does not empty the live screen at once. Starting the next meeting on the same page clears the earlier transcript, cards and to-dos. **Context** is not cleared.

## Steps
1. Make sure the earlier meeting has ended with **End**.
2. If you need its to-dos, select **Export action items** before you start the next meeting.
3. To empty the screen sooner, select **Clear all** (trash icon on the toolbar). There is no confirmation. Saved meetings and documents are not deleted.
4. Check **Context**; it is kept in your browser. Edit or delete it yourself.
5. Select **Record** for the new meeting.
