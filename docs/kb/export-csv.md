## Short answer
`meetings.csv` has one row per saved card. It has no transcripts, to-dos or recordings, skips meetings without cards, and **includes cards you deleted from the live screen**.

## Steps
1. Select **Export CSV** (download icon).
2. Open `meetings.csv`. Rows show the meeting ID, title, start and end times, word count, and the card's tag, title and text.
3. Review it for deleted cards and private content before sharing.
4. For to-dos, use **Export action items** while the list is on screen. For a transcript, copy it from **History**.
