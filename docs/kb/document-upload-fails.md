## Short answer
The message shows whether the cause is the file's size, type or text, or a trial limit.

## Steps
1. **File too large (max 20 MB).**: use a smaller file.
2. **Unsupported file type**: save it as `.txt`, `.md`, `.pdf`, `.docx`, `.html` or `.htm`. Old `.doc` files are not supported.
3. **No text content found**: the file has little or no readable text, such as a scanned PDF. Use a version with real text.
4. **Extraction failed**: the file could not be read. Re-save it and try again.
5. **trial_doc_limit**: the trial's 2 uploads are used, even if you removed a file. Activate a license.
6. **trial_expired**: the trial has ended. Activate a license.
