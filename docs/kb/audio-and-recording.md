## Short answer
Choose a microphone and transcription mode; only the desktop app shows **Record A/V**.

## Steps
1. Obtain meeting consent before capture.
2. Select a **Microphone source**. Use **Whisper** or, in Chrome, **Web Speech**.
3. Select **Start listening** and allow microphone access if prompted.
4. In the desktop app, select **Record A/V** to start screen and audio recording, then select it again to stop.
5. If microphone access is denied, grant access in the operating system or browser and retry. Restart listening after changing Echo, Denoise, or AGC.
