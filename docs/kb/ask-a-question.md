## Short answer
Set a wake word, start listening with participant consent, and say the word followed by your question.

## Steps
1. Open **Settings**, enter a **Wake word**, configure an available AI provider, and select **Save**.
2. Confirm that the badge next to the presence orb shows the expected word.
3. Obtain participant consent, start a meeting, and select **Start listening**.
4. Say the wake word followed by a question. Listen for the answer; select **Start listening** again to stop capture.

This build has no text question box and does not guarantee a displayed citation for every answer.
